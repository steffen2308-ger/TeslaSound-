# TeslaSound

Experimentelle Android-App für virtuelle Motorgeräusche über die normale Bluetooth-Medienausgabe. GPS liefert die Geschwindigkeit, Smartphone-Sensoren die Beschleunigung. Kein Fahrzeugzugriff, keine Internetverbindung, keine Speicherung von Standortdaten.

Bedienung im Stand: Handy sicher befestigen, Tesla als Bluetooth-Medienquelle auswählen, Standortfreigabe erteilen und Sound starten. Lautstärke moderat einstellen. Nicht während der Fahrt bedienen. Kein Ersatz für Fahrzeugwarnsignale oder AVAS.

Der Debug-Build ist für Android 8+ vorgesehen. GitHub Actions: APK-Build ausführen und das APK-Artefakt herunterladen, entpacken und installieren. Das Projekt ist experimentell; Bluetooth-Latenz und Sensorverhalten im Fahrzeug müssen getestet werden.

Inoffizielles Projekt ohne Verbindung zu Tesla.
